# Hozzájárulás

1. Új kéréshez nyiss új issue-t a megfelelő [sablonnal](https://github.com/tnyari/RoboAssist/issues/new/choose).
2. Ellenőrizd a [roadmapet](https://github.com/tnyari/RoboAssist/issues/2), a függőségeket és az elfogadási feltételeket.
3. Írj munkakezdési kommentet. Javasolt branch: `issue-<szám>/<rövid-név>`.
4. Új vagy maradó feladathoz készíts külön aljegyet, és kösd össze a szülővel mindkét irányban.
5. A fontos mérföldköveknél kommentben rögzítsd az eredményt, ellenőrzést és következő lépést.
6. A PR-ben hivatkozz a jegyre. `Closes #N` csak akkor, ha az összes vállalt feltétel és aljegy kész; különben `Refs #N`.
7. A lezáró komment tartalmazza a bizonyítékokat és minden maradék feladat linkjét.

A GitHub műveletek a GitHub bővítményen keresztül történjenek. Projektet és egyedi címkéket ne hozz létre. Részletek: [munkarend](docs/github-workflow.md), [fejlesztői indulás](docs/development.md), [AGENTS.md](AGENTS.md).
